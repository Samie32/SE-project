# Dữ liệu và mẫu kiểm thử

Để cả nhóm có dữ liệu trên ClinicCare, dùng [hướng dẫn nạp local](../../../../data_demo/README.md). Trình nạp tạo dữ liệu qua API hiện có.

| Thư mục | Nội dung |
| --- | --- |
| [backend/](backend/README.md) | Ví dụ request, danh sách tài khoản seed, snapshot và truy vết theo hợp đồng API 1.0.0. |
| `generated/` | Đầu ra sinh theo ngày, được Git bỏ qua. Dùng thư mục `backend-YYYY-MM-DD/` để thử API hiện tại. Đầu ra thiết kế cũ nằm dưới `design-0.1/`. |
| [archive/design-0.1/](archive/design-0.1/README.md) | Fixtures, ví dụ API, kịch bản và báo cáo kiểm tra cũ để đối chiếu thiết kế. |
